# Dhriti Nagar — CV

Live, self-contained CV (single `index.html`) plus PDF downloads.

## Deploy on Vercel
1. Push this folder to a new GitHub repo.
2. On vercel.com → Add New → Project → Import the repo.
3. Framework preset: **Other**. Root: `/`. No build command, no output dir.
4. Deploy → you get a `*.vercel.app` link. Every `git push` redeploys automatically.

## Files
- `index.html` — the CV web page (Download-PDF button included)
- `Dhriti_Nagar_CV.pdf` — print/share PDF
- `Dhriti_Nagar_MicroProposal.pdf` — research micro-proposal
